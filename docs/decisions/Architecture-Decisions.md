# Rejestr Decyzji Architektonicznych (Architecture Decision Records)

Rejestr dokumentuje kluczowe decyzje projektowe i techniczne podjęte podczas rozwoju projektu **Triki Music Controller**.

---

## Lista Decyzji (ADR)

1. [[ADR-001-Strict-Zero-Emoji-Policy]] — Bezwzględny zakaz używania emotikonów w całym projekcie (kod, UI, komunikacja, commity, dokumentacja).
2. [[ADR-002-Dual-Platform-Core-Parity]] — 100% parzystość algorytmów Core między C# (.NET 10) a Kotlin (Android).
3. [[ADR-003-Button-Hold-For-Brightness]] — Wymóg przytrzymania fizycznego przycisku przy regulacji jasności ekranu w pozycji 90°.
4. [[ADR-004-Dynamic-Version-Binding]] — Dynamiczne wiązanie wersji aplikacji i bezkolizyjne zamykanie procesu podczas aktualizacji Inno Setup.
