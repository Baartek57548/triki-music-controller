# Ekran Sterowania i Mapowania Gestów

Zakładka **Sterowanie** skupia wszystkie interakcje ruchowe oraz konfigurację fizycznego przycisku w jednym miejscu.

Powiązane węzły:
- [[Gyro-Volume-Control]] — panel głośności i bramki stabilizacji.
- [[Inverted-Capsule-Gestures]] — suwak konfiguracji kąta obrotu ($90^\circ–360^\circ$).
- [[Button-Interpreter]] — kafelki wyboru akcji dla 1x, 2x i 3x kliknięcia.
- [[Edge-Brightness-Control]] — objaśnienie gestu jasności na krawędzi.

---

## Zawartość Ekranu

1. **Karta Głośności Systemowej (Żyroskop)**:
   - Dynamiczny wskaźnik stabilizacji (pasek postępu 0–2 s).
   - Podgląd aktualnego poziomu głośności i statusu gotowości do ruchu.

2. **Karta Odwróconego Kapsla (Zmiana Utworu)**:
   - Suwak kąta docelowego (`90°`, `180°`, `200°`, `270°`, `360°`).
   - Wizualizacja postępu obrotu w czasie rzeczywistym.
   - Wskaźniki kierunku: w lewo (Next) / w prawo (Previous).

3. **Karta Fizycznego Przycisku**:
   - Mapowanie pojedynczego kliknięcia (Play / Pause).
   - Mapowanie podwójnego kliknięcia (Like / Next / PlayPause).
   - Mapowanie potrójnego kliknięcia (Dislike / Previous / PlayPause).

4. **Karta Ostatniej Akcji Multimedialnej**:
   - Kompaktowy podgląd ostatnio wykonanej operacji wraz ze statusem i znacznikiem czasu.
