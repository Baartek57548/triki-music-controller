# Wydanie v3.0.0 — Nowy Motyw Material Design 3 i Synchronizacja Zakładek

Data publikacji: 2026-09-01  
Wersje binarne: Windows `3.0.0.0`, Android `3.0.0`

Powiązane węzły:
- [[Windows-Architecture]] & [[Android-Architecture]] — motywy i stylistyka.
- [[Controls-Screen]] — synchronizacja nawigacji.

---

## Główne Zmiany

1. **Spójny Wygląd Material Design 3 w Windows i Androidzie**:
   - Wprowadzono ciemną paletę kolorystyczną (Obsidian / Emerald) oraz świeży motyw jasny z zaokrąglonymi rogami kart ($18–22\text{ px}$).
2. **Synchronizacja Nawigacji NavigationView**:
   - Naprawiono przełączanie zakładek z poziomu przycisków na stronie głównej, synchronizując zaznaczenie w bocznym pasku nawigacji.
3. **Usprawnienia Telemetrii**:
   - Stabilizacja wykresów i wskaźników położenia w czasie rzeczywistym.
